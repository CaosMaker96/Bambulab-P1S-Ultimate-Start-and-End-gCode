An Edited Version of [Ultimate start and end gcode for Bambulab P1S/P1P printers](https://github.com/CaosMaker96/Bambulab-P1S-Ultimate-Start-and-End-gCode) by [CaosMaker96](https://github.com/CaosMaker96)

## Changes made in this Version
- Several minor G-Code improvements
- Second Automatic Bed Levelling removed
- Shake sequence trimmed from 8 to 5 moves
- Wipe sequence trimmed
- Added a [better purge line](https://www.reddit.com/r/BambuLab/comments/1imvk2f/smaller_purge_line_for_p1pp1sx1c_reclaimed_bed/) (uses less bed space with less filament waste)

## Testing
Tested with OrcaSlicer on my Default P1S using BambuLab PLA and Elegoo Rapid PETG on multiple prints. No AMS was used, so the AMS Code remains untested.
